Una casa de cambio de divisas necesita devolver el cambio exacto
a sus clientes usando el menor número de monedas posible.
Dado un valor a devolver y una lista de monedas disponibles
ordenadas de mayor a menor, se pide calcular cuántas monedas
de cada tipo se necesitan para devolver el cambio exacto.

Entrada:
  La primera línea contiene un número (entero o decimal)
  con el valor a devolver.
  La segunda línea contiene un entero M con el número de
  tipos de moneda disponibles.
  La tercera línea contiene M números ordenados de mayor
  a menor con el valor de cada tipo de moneda.

Salida:
  Una línea con la cantidad de monedas de cada tipo
  necesarias para devolver el cambio, separadas por espacios.

Ejemplo de entrada:
  87
  9
  50 20 10 5 2 1 0.5 0.2 0.1

Ejemplo de salida:
  1 1 1 1 1 0 0 0 0
