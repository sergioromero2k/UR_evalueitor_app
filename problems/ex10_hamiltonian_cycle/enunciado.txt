Un grupo de turistas quiere visitar varias ciudades en un viaje
organizado. El objetivo es encontrar un recorrido que pase por
TODAS las ciudades exactamente una vez y regrese al punto de partida.
Este recorrido se conoce como Ciclo Hamiltoniano.

Usando Backtracking, se pide encontrar e imprimir TODOS los ciclos
hamiltonianos posibles que comiencen desde el nodo 0.

Entrada:
  La primera línea contiene dos enteros N y M, donde N es el número
  de ciudades y M el número de conexiones entre ellas.
  Las siguientes M líneas contienen dos enteros U V indicando
  que existe una conexión entre la ciudad U y la ciudad V.

Salida:
  Una línea por cada ciclo hamiltoniano encontrado, con los nodos
  del ciclo separados por espacios.
  Si no existe ningún ciclo hamiltoniano, imprime "SIN CICLO".

Ejemplo de entrada:
4 6
0 1
0 2
0 3
1 2
1 3
2 3

Ejemplo de salida:
  0 1 2 3 0
  0 1 3 2 0
  0 2 1 3 0
  0 2 3 1 0
  0 3 1 2 0
  0 3 2 1 0
